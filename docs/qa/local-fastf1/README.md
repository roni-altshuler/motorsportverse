fixtures**, generated by the actual Python converter. No real telemetry, local
historical cache, circuit asset or live service was used. Screenshots retain
their synthetic filename and invented driver name.

  Exact-head F1 CI provides a separate full-suite check.

## Reproduce only the synthetic browser check

With F1 development dependencies available, generate the test-only file outside
Git, then build and exercise the real export:

```sh
PYTHONPATH=projects/f1-predictions/src:projects/f1-predictions/tests python - <<'PY'
from pathlib import Path
from test_export_local_capture import capture
Path('/tmp/motorsport-fastf1-synthetic.ndjson').write_text(capture(), encoding='utf-8')
PY
cd projects/f1-predictions/website
PAGES_BASE_PATH=/motorsportverse/projects/f1 npm run build
cd ../../..
node scripts/qa_circuit_workspace.mjs /tmp/local-fastf1-qa \
  /motorsportverse/projects/f1 /tmp/motorsport-fastf1-synthetic.ndjson
```

The runner requires the original synthetic fixture marker and identity. It is
not a real-session verifier. Usage, source semantics, optional dependency and
separate software/data licenses are documented in
[Local FastF1 capture export](../../FASTF1_LOCAL_CAPTURE.md).
