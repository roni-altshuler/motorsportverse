# RaceIQ WRC website

The FIA World Rally Championship prediction site — a Next.js 16 static export
reusing the MotorsportVerse design system, re-themed to the WRC blue accent
(`#0F62FE`). A rally is a single classification per round (no sprint, no
qualifying grid), and **surface** (gravel / tarmac / snow) is the signature
variable, surfaced as a colour-coded chip everywhere.

## Pages

| Route | Content |
|---|---|
| `/` | Hero, title-fight favourite + top-5 title odds, next-rally predicted podium |
| `/standings` | Crews + manufacturers championship tables (client-tabbed) |
| `/calendar` | Full season calendar with surface chips and completed/upcoming status |
| `/race/[round]` | One rally: predicted classification, win/podium probabilities, charts |
| `/driver/[code]` | Crew profile: form, points progression, predicted-vs-actual |
| `/accuracy` | Honest model-vs-baseline scoring (beats championship form?) |

## Data

All pages read the JSON under `public/data/` (`wrc.json` + per-round
`rounds/`, `probabilities/`, `forward_eval/`), generated by the Python pipeline
in `projects/wrc-predictions/`.

## Develop

```bash
npm install
npm run dev      # http://localhost:3000
PAGES_BASE_PATH= npm run build    # static export -> out/
```

## Reuse

The shared MotorsportVerse design system (`components/ui`, `components/magicui`)
is copied verbatim from the F1 flagship and kept byte-identical by
`scripts/sync_shared_ui.mjs`; only the pages, nav, and data layer are
WRC-specific.
